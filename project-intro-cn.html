Local Project Overview

NEGA AI 语音对话项目

NEGA AI 是一个基于 Next.js 的实时语音对话网页应用，前端通过 ElevenLabs Conversational AI SDK 启动语音会话，后端 API 负责向 ElevenLabs 获取带签名的会话 URL。

查看英文 README 查看图文教程 试听内置语音

项目定位

实时语音交互

页面会请求麦克风权限，通过 ElevenLabs 的会话能力与 AI Agent 建立实时对话。

可视化会话状态

界面包含连接状态、Agent 头像、实时波形和 Agent 消息展示，方便用户判断当前会话阶段。

本地可运行模板

项目已包含 Next.js、Tailwind CSS、React 组件和 API 路由，可作为语音 AI 应用的二次开发起点。

技术栈

Next.js 15 React 19 RC TypeScript Tailwind CSS ElevenLabs React SDK Framer Motion Lucide React

关键文件

  • app/page.tsx：首页入口，渲染语音对话组件。
  • components/ConvAI.tsx：语音会话主逻辑和界面状态。
  • app/api/signed-url/route.ts：获取 ElevenLabs signed URL。
  • public/avatar.png：Agent 头像资源。
  • public/American.mp3：内置语音配置参考音频。
  • doc/：项目图文教程截图。

本地运行

pnpm install
pnpm dev

如果使用 npm、yarn 或 bun，也可以按 README 中的命令启动开发服务。

环境变量

运行语音会话前，需要在本地配置 ElevenLabs 相关变量：

AGENT_ID=你的 ElevenLabs Agent ID
XI_API_KEY=你的 ElevenLabs API Key

工作流程

  • 用户点击 Start conversation 后，浏览器请求麦克风权限。
  • 前端调用 /api/signed-url，服务端使用 AGENT_ID 和 XI_API_KEY 请求 ElevenLabs。
  • 拿到 signed URL 后，前端通过 useConversation 启动语音会话。
  • Agent 回复时，页面显示文本消息，并通过波形与头像状态反馈当前连接情况。
